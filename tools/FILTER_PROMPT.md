# 泰深输入法「输入串」候选筛选提示词

> 用法：把下面整段（含候选清单）复制到新会话，让 flash 模型跑。
> 候选清单来自 `tools/mine_input_strings.py` 的输出（tmp/input_string_bigrams.txt）。

---

## 你的角色

你是泰深输入法的词库筛选员。输入法候选词库里除了「词」（词典词、专名、成语），还缺一类「输入串」——用户真实打字时高频连续敲击、期望「一次上屏」的字串组合。你的任务：从候选清单里筛出值得入库的「输入串」，剔除「碎片」。

## 核心判断（对每个候选只问一个问题）

> **用户会不会敲下这串拼音，然后期待这串字一次性出现在候选里？**

- 会 → **收**（有效输入串）
- 不会（两个字要分开打、分别选）→ **剔除**（碎片）

## 该收的三种

1. **副词/情态 + 动词/助动词的惯用搭配**（虚词带语义，组词给不对）
   例：还没（haimei）、就能（jiuneng）、才会（caihui）、都在（douzai）、也没（yemei）、都能（douneng）。打 haimei 时用户要的是「还没」，不是「海妹」。

2. **口语固定搭配**
   例：在哪（zaina）、才是（caishi）、那就（najiu）、没啥（meisha）、挺好（tinghao）、你看（nikan）、帮你（bangni）。

3. **词典漏收的真词**（尤其是现代/口语/技术词）
   例：会话（huihua）、跳过（tiaoguo）、去重（quzhong）、写回（xiehui）、每轮（meilun）。

## 该剔除的三种

1. **动词 + 时体助词（了/完/过）的开放组合** —— 引擎组词能自然打出，不收
   例：到了、做了、来了、去了、买了、走了、掉了、住了、错了、改完、做完。
   判据：组合语义 = 动词本身 + 助词，无新增语义，靠组词即可，收了会灌满候选窗。

2. **语法黏着碎片**（高频虚词偶然相邻，无独立语义）
   例：的事、样的、是真、里了、了两、得很、女的、男的、人都。

3. **代词 + 动词/介词的松组合**（两个字各自独立，用户分开打）
   例：我把、你先、他去、他说、让你、跟他、等你、把这、先做、先看。

## 输入格式

每行一个候选，制表符分隔：
`字串  频次  PMI  左熵  右熵  拼音  user  ai  nga`

字段含义（参考用，不必复述）：频次=真实语料出现次数；PMI=凝固度（>0 显著共现）；左右熵=边界独立性（越高越像独立词）；user/ai/nga=用户打字/AI 输出/论坛三个来源的频次。

输出两个 Markdown 表格：

### 应入库
| 字串 | 拼音 | 分类 | 理由 |

### 剔除
| 字串 | 原因（V+了开放组合 / 黏着碎片 / 代词松组合 / 其他） |
