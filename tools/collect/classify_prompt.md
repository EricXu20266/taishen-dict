# 词库候选三档分级提示词

把采集脚本产出的候选（`news_candidates.tsv` / `dumps_by_domain.json`）分批交给 LLM，按下面标准分级。

建议每批 300–500 个，输出严格按 `词<TAB>档位` 格式，便于脚本直接读取。

---

## 提示词正文（复制下面整段，末尾附候选清单）

你是中文输入法的词库筛选员。我会给你一批候选词，每个词后面是它在新词语料里的出现频次。

你的任务是把每个候选判成三档之一：

**A —— 通用词 / 术语**
用户在不特定语境下会打出来的词。
例：同比增长、资本开支、世界模型、光模块、泡利不相容原理、烯烃复分解反应、折叠屏、工作负载

**B —— 专名**
人名、地名、机构名、事件名、作品名、产品名、天体名。
这类**要收**，但优先级要低——用户不会天天打，可一旦要打就得有。
例：宇树科技、王兴兴、姆巴佩、宁德时代、哈勃空间望远镜、九寨黄龙、讯飞输入法、朱令铊中毒事件

**C —— 丢弃**
- 碎片：词尾或词首被截断的（神舟十 → 应为神舟十三号；业绩预 → 应为业绩预告；癌症前 → 癌症前筛）
- 虚词组合：也是、中的、这是、点此、年同期
- 生僻字：输入法打不出来的字（䲟鱼、䴓属、䴕形目）
- 百科导航页：XX列表、XX比较、XX索引
- 书名句/长句：不精确和不确定的管理

---

## 判断要点

1. **先问「用户会不会敲这串拼音」**。会敲 → A 或 B；不会 → C。
2. **A 和 B 的分界是「泛化程度」**。`折叠屏` 是品类（A），`华为Mate X5` 是产品（B）；`天文现象` 是概念（A），`马头星云` 是天体名（B）。
3. **截断词一律判 C，但可以在备注里给出完整词**（如 `神舟十` → 建议 `神舟十三号`）。
4. **台湾译法要标出来**：`全球暖化` 大陆是 `全球变暖`，`萤光显微镜` 是 `荧光显微镜`。这类判 C 并备注大陆写法，或直接按大陆写法收 A。
5. **不要因为生僻就判 B**。生僻专名（`阿克西斯`、`灵薄狱`）对输入法无价值，判 C。
6. **不确定时优先判 C**。词库宁缺勿滥，误收一个碎片比漏收一个词代价高。

---

## 输出格式

```
同比增长	A
宇树科技	B
神舟十	C	应为神舟十三号
也是	C
```

只输出结果，不要解释。批次末尾附一行统计：`A=n B=n C=n`。
